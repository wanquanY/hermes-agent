# Code Samples

这是一组用于测试功能的常用代码文件。

## 包含文件

- `hello.py`：Python 示例
- `app.js`：JavaScript 示例
- `component.tsx`：React + TypeScript 示例
- `index.html` / `styles.css`：网页示例
- `server.go`：Go HTTP 服务示例
- `main.rs`：Rust 示例
- `Example.java`：Java 示例
- `schema.sql`：SQL 示例
- `config.yaml`：YAML 配置示例
- `data.json`：JSON 数据示例

## 用途

用于测试文件创建、读取、搜索、语法高亮、格式化、代码修改等能力。
